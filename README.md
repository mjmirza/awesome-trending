# daily-trends

A public, daily snapshot of what is moving on X (Twitter) and GitHub.

Each day this repository records the top X trends (worldwide, Germany and the United States when available) and the repositories GitHub lists as trending. The files are updated daily. Nothing here is invented: volumes, star counts and context come from the sources cited in that day's file.

## How the files are organized

Snapshots live at `YYYY/MM/YYYY-MM-DD.md`.

Example: the file for 19 November 2026 is [`2026/11/2026-11-19.md`](2026/11/2026-11-19.md).
