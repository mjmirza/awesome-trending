# Add a badge

Use this badge only if your repository actually appeared in [awesome-trending](https://github.com/mjmirza/awesome-trending) — for example on the daily GitHub trending table or in an industry list. Do not add it just because you submitted an issue.

Markdown:

```markdown
[![Featured in awesome-trending](https://img.shields.io/badge/Featured%20in-awesome--trending-blue)](https://github.com/mjmirza/awesome-trending)
```

HTML:

```html
<a href="https://github.com/mjmirza/awesome-trending">
  <img src="https://img.shields.io/badge/Featured%20in-awesome--trending-blue" alt="Featured in awesome-trending">
</a>
```

The badge links back to https://github.com/mjmirza/awesome-trending.
